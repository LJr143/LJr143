# ITKILLS

> Building the web, and learning how to break and defend it.

ITKILLS is where I collect my work across two sides of IT: **full-stack web development** and **cybersecurity**. I build applications with Laravel, .NET Core and Angular, and I test and harden systems using offensive (red team) and defensive (blue team) security tools.

The goal is simple: write software that works, and understand how attackers think so that software stays secure.

## 🔗 Where Dev Meets Security

Doing both gives me a useful perspective:

- **As a developer**, I know how apps are built: routing, auth, databases, APIs.
- **As a security tester**, I know where they usually break: injection, broken access control, misconfigurations, exposed secrets.
- **The result**: I try to build with security in mind from the start, not as an afterthought.
